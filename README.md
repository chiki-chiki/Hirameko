# ひらめこ 🌱

ふと思いついた「ひらめき」を、気軽にメモしておける癒し系アイデアストックアプリです。

---

## 🔧 機能一覧

- 💡 アイデアの登録（タイトル＋メモ＋日付）
- 📝 アイデアの編集・保存
- ❌ アイデアの削除
- 💾 localStorage による保存（リロードしても残る！）
- 🎨 Tailwind CSS によるやさしいUI（INFPっぽさを意識）

---

## 🚀 使用技術

- React + TypeScript
- Vite
- Tailwind CSS
- localStorage（ブラウザ内保存）
